How to label (press H to show or hide)
  1. Pick your video above (the assigned person is shown under each name) and type your name top right.
  2. First pass at 1x: watch the whole video and spot events. Press I roughly where one starts, O where it ends, pick the class (letter key or dropdown), press Enter. Rough is fine here.
  3. Second pass at 0.25x: click each event in the list, step frames with , . and fix start and end exactly (the =now buttons copy the current frame time).
  4. Follow the start/end rule of the class shown on the right. Two events of the same class at the same time: make ONE segment covering both. Different classes may overlap. Event still going at the end of the video: end = video end (E).
  5. When unsure, still add it and write a note saying why.
  6. Work is saved to the server about 2 s after every change (status top right) and also kept in this browser. Clear the Validate panel before you finish.
